# 第2课 跨机通信（ssh）：两台电脑、没有中间服务器时消息怎么走

第1课里，消息从未离开过一台机器：名字在本机注册表里解析，投递走本机管道。这一课把范围扩大一圈——两台电脑，各跑着各的 agent，中间没有任何服务器。crosschat 的答案是复用 ssh：你在两台机器之间配一次免密登录（这件事运维世界已经做了三十年），消息就沿着这条旧路走，crosschat 自己零新增配置。

## 学完这课你能做到

- 把两台机器配成 ssh 免密联邦，并用一条命令自证
- 让本机 agent 给另一台机器上的 agent 发第一条跨机消息，读懂回执
- 收到跨机消息后照抄回信，不写任何地址——回程自动选路
- 正文超过大小上限时，用 scp 旁路把大内容送过去
- 讲出一条跨机消息的五步链路，与每一步上隐式发生什么

## 前置

- 读完第1课（信封、reply-hint、回执三态这些词不再解释）
- 两台能互相 ssh 的机器；只有一台也不要紧，[2.3 的一台机器的自环](lesson-2/03-deploy-config.md#一台机器的自环)给了练习路径
- Windows 机器需要管理员权限开一次 sshd；Linux 机器需要 root 或 sudo
