# 第1课 单机通信：一台电脑里，消息怎么从一个 AI 到另一个 AI

一台电脑上可以同时跑好几个 AI 会话——🤖 claude 在一个终端里改代码，🤖 codex 在另一个终端里跑任务。它们离得再近也互相听不见：每个会话都是一间隔音室，你说的话只有你终端里的那位听得见。crosschat 让它们按名字互发消息：没有服务器、没有常驻进程，一条命令就是一次完整投递。这一课发起第一次对话、读懂每一条回执——装备在前言的[环境搭建](../preface/04-env-setup.md)里备齐，这也是全书的地基：后面两课的跨机通信，全部建立在本课的机制之上。

## 学完这课你能做到

- [完成环境搭建](../preface/04-env-setup.md)，doctor 全绿
- 起两个命名会话，让 claude 与 codex 按名字互发消息
- 读懂回执三态与续话短柄，收到消息后照抄回信、不写任何地址
- 知道每种信息去哪查：名单用 status、环境用 doctor、账本在 send-log
- 讲出一条消息在本机的完整旅程，与两条投递腿各自的脾气

## 前置

- 会开终端、会装 npm 包；Node.js 都还没装也不要紧，[环境搭建](../preface/04-env-setup.md)从零开始
- 有 claude 或 codex 至少一个账号（两个都有最顺；只有一个也能走完本课大半——单侧缺席是合法状态，doctor 会这么告诉你）
