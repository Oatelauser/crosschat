# 3. 符号约定

## 角色符号

全书对话实录用三个符号，一看即辨：

| 符号 | 是谁 |
|---|---|
| 👤 | 你——操作者，敲命令的人 |
| 🤖 | agent——AI 会话（Claude Code / Codex CLI） |
| 📨 | agent 收到的外来消息——crosschat 信封 |

## 命令实录

实录块长这样（示意）：

```console
> crosschat status
本机会话: claude 1 · codex 1
```

`>` 开头的行是敲进终端的命令（可以照抄），其余行是运行输出。实录块都带语言标注（console / powershell / bash）；图放 text 块，等宽字体下对齐不散。
