# 怎么读

## 顺序读最省力

教程三课是主线，每课学完一个闭环：第1课跑通单机对话，第2课打通两台机器，第3课组起一张网。每课开头有「学完这课你能做到」和「前置」，课末有「一句话记住」。

| 课 | 主题 | 要回答的问题 |
|---|---|---|
| 第1课 | 单机通信 | 一台电脑里，消息怎么从一个 AI 到另一个 AI |
| 第2课 | 跨机通信（ssh） | 两台电脑、没有中间服务器时消息怎么走 |
| 第3课 | 跨机通信（tcp） | 一群电脑、只开一个端口时消息怎么走 |

全书一条线索：一条消息是怎么送到的。每课把答案的范围扩大一圈——一台电脑、两台、一群。

## 其余三部怎么用

- 指南：出了问题查这里，一条一页，给出具体步骤
- 参考：要查就看，全是表——命令、地址格式、错误码
- 原理：想弄懂再看，讲设计为什么这样定；不影响使用，可最后读或永远不读

## 读这本书的前提

- 一台 Windows 电脑（演示命令以 Windows 为主，Linux 对应命令每步一行带过）
- 第2课起最好有两台机器；没有第二台，课内给了单机自环的练法
- 书教最新已发布版 crosschat，内容随仓库更新
