# 1. 这本书讲什么

> 🚧 书还在写：目录已定稿，前言与第2课已上线，其余章节逐模块赶来。

crosschat 是一个命令行工具：它让 AI 会话互相发消息。同一台电脑上的 Claude Code 和 Codex CLI 可以对话，不同电脑上的也可以。

没有它的时候，你要在两个终端之间人工复制粘贴：A 说一段，你复制，切窗口，粘给 B；B 回了话，再复制回来。消息走得通，但每一跳都是你的手，两个 agent 自始至终不知道对面是谁。

这本书教三课，每课回答一个问题：

1. 一台电脑里，消息怎么从一个 AI 到另一个 AI（[第1课 单机通信](../tutorial/lesson-1.md)）
2. 两台电脑、没有中间服务器时消息怎么走（[第2课 跨机通信（ssh）](../tutorial/lesson-2.md)）
3. 一群电脑、只开一个端口时消息怎么走（[第3课 跨机通信（tcp）](../tutorial/lesson-3.md)）

给谁读：会开终端、会复制粘贴就够了——安装从 Node.js 开始教，不需要编程基础。

不教什么：不教 Claude Code / Codex 自己怎么用（各自官方文档的事）；不教 ssh 运维大全（只教跨机用到的那一段）。crosschat 的边界很清楚：只做消息投递，AI 会话的生死归原生命令管。
