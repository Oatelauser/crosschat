# T06 · 外壳与共享交互

以用户已确认的v6为规格，T06授权于2026-10-22。实现与测试使用同一登记和模型，真实业务读取/写入在后续资源任务接入。

## 启动与布局

- 单npm包、TypeScript；`crosschat tui`动态加载Ink/React，普通命令不加载终端框架或绑定输入。
- 默认ctx，保留本机入口。只列已配置SSH/TCP，不启动批量探测；配置身份提示与当前已认证权限分开。记忆上次选中，不自动进入。
- 顶部连接/权限，统一输入及最多两行命令提示，中部连续资源表，底部当前动作及全局帮助；无固定多分栏。
- 所有列有显示格硬上限，窄终端压缩/隐藏次要列，表格单行不溢出。完整值只读详情可滚动/复制。控制序列作为数据清理，不执行。

## 全局行为

- `:`命令补全和当前资源实时筛选；Tab/Shift+Tab及上下切候选。精确命令/已选候选Enter切页，其他Enter保留筛选。`/`纯筛选解决资源名重名。Esc撤销草稿，恢复进入输入前状态。
- 列表↑↓/j/k、Home/End、PgUp/PgDn、r、S、Esc、?、q与Ctrl+C均由登记产生帮助。Esc先清筛选再返回；返回恢复稳定ID、排序、滚动和筛选。
- d/Enter详情只读；详情支持滚动、查找、完整字段复制、返回。输入/详情/帮助/弹层隔离列表写快捷键。
- 资源名/别名/列/动作/权限说明/按键是一个登记。未来资源和Provider可扩展，未知原生状态保留原值并显示中文说明。

## 弹层与异步

- 写动作仅来源资源列表可发起。弹层固定ownerResourceId/contextId/targetId；表单编辑、预检、影响确认、提交分明，默认取消。
- 确认前重新查权限/目标；刷新不把目标替成另一行。失败保留值，成功回原列表并按returnPolicy恢复/选择结果。
- 取消已发写请求表示停止等待、结果待核实；业务回滚与重发均由应用能力决定。
- 每次读取有AbortController与代际，换页/刷新/退出释放旧读取并丢弃迟到结果。Ctrl+C先取消当前读取，无读取则退出；弹层Ctrl+C取消弹层。
- T06默认只启用ctx与通用交互；后续资源显示尚未启用及可返回路径，测试通过注入Adapter验证完整交互。配置列表不冒充远端已认证或已采集数据。

## 验证出口

- 公开接缝测试：命令/筛选/撤销、稳定选择/返回、第三资源/未知状态、只读详情、固定目标与权限拒绝、取消/迟到结果、Unicode/控制序列、无配置副作用。
- 入口隔离及非TTY；真实终端键盘、粘贴、窄宽resize、Ctrl+C/异常退出后raw/cursor/alternate screen恢复。renderer测试不能替代真实终端验收。
- 对应检查及npm run check通过后记录证据，删除T06活动条目和已满足依赖；后续任务保留。
