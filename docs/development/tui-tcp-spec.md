# TUI TCP浏览与管理规格

2026-10-22用户授权；正常流程、不赶时间，现有功能变化先确认。基线`393f1ad`，1546通过/11既有跳过。root统一提交，其他会话改动保持。

## 浏览合同

- 本机stars仅本机broker托管星；TCP ctx仅所绑定的一星，不能枚举其他星；SSH管理无接口时明确禁用，不改成本机执行。
- 星默认machines，v到全星sessions；machines的Enter进入机器sessions、d只读机器详情。全星sessions的Enter进入所属机器sessions、d只读会话；机器sessions的Enter/d查看会话详情。每行带机器名/mid8，内部保留完整机器ID与包含机器的会话引用。
- 默认册内成员（在线/下线独立），b切当前节点/所有在线节点可发现范围；发现<=3并发且完整分页，匿名默认包含，未入册与原生忙闲分别显示，来源失败/离线保留partial。
- 可发现范围保留未被原生结果精确命中的持久册位，含离线/失败节点；不把未发现当作删册或0会话，不为这些投影虚构原生状态。完整机器/工具/原生引用才可合并，临时进程不冒充册位。
- machines、members、keys分别表示已绑定机器、会话登记和接入/管理凭证；未使用钥匙不能充作机器；所有列表字段限宽、详情全值，帮助与动作同源。
- 本机经严格验证的静态台账可提供staticComplete，供冷态管理预检使用；实时完整性仍为partial、活性unknown。执行端继续独立核实broker热冷状态，远端partial不因该标志放行。

## 管理合同

- 写动作从所属列表发起，固定连接/星/目标，默认取消；提交重新核对权限、身份和影响，失败保留输入，成功回原位置/新对象。
- 星增删改仅broker本机；节点发钥与删节点须星管理员或本机broker主；发吊管理钥仅broker本机。普通成员保持本星读取与既有册位操作；收编固定所选 node 的完整原生引用，由该 node 核验，删册使用既有精确删册。
- 新机器接入预填星/可达地址，默认一份配置。专属一次性结果态提供配置/接收机命令复制，离开丢弃秘密并清当前终端画面，普通行/详情/偏好/错误不存秘密；不能清除外部终端录像或已复制OS剪贴板。
- 显示名只允许当前机器，区分global/star覆盖和实际连接生效；远端任意机器改名/日志无接口则说明去对应SSH，不虚构成功。
- 删除/撤钥保留既有立即撤权与自动保障暂停；无回执不冷写/不盲重试，写后取消不能认作回滚。冷写只在确认broker未运行时开放，不能据坏/缺快照推断安全冷态。

## 既有功能批准

1. **已批准**：新增只读星快照，同一DTO供本机与WS；WS仅成员/星管理员本星，返回完整机器ID、连接、成员、安全凭证元数据/不可逆revision，不返回钥匙；新读接口不记管理审计，原list读取/审计保持。使用admin-op action=star-snapshot及adminPipe同名op，不做旧端降级。
2. **已批准**：TUI删节点/吊管理钥/删星新增expected版本约束，在broker/冷mutation同一步核对。目标替换、label复用或删星影响新增则拒绝；旧CLI不传保持，不做旧端降级。凭证核验credentialRevision和显式machineId(null=未绑定)；删星核验完整静态starRevision。
3. **已批准**：原管理审计行保留文字并追加完整starId作用域元数据，原动作/频率/权限保持；多星显示名动作同一行记录全部受影响星。TUI按稳定身份筛选，旧行无标识时明确无法准确归属。
