# TUI 工作区改造：已批准规格

2026-10-23。用户完成 grilling 访谈后明确“没有问题的话，开始实施”。本规格记录本轮批准，旧规格与此冲突时以此为准；未涉及的既有 CLI、权限、原生工具与持久化合同保持。

## 工作区与界面

- ctx 是全局只读看板，展示本机、已有 SSH 和 TCP 目标，允许查看、筛选和导航；添加、检测与管理动作归各工作区。
- 独立 `:local`、`:ssh`、`:tcp` 入口。工作区负责导航和资源目录，执行身份仍由实际连接核验；TCP 工作区同时支持本机 broker 管理和远程星连接，不因界面分类改变权限。
- TCP 首次选择目标，以后恢复有效的上次目标；星列表可新增、修改、删除星。进入 star 默认成员视图，1/2/3 直接切成员、节点、会话；会话视图执行完整发现，包含匿名及未入星会话，来源失败/持久册位不得假装完整。
- 节点=机器，成员=登记的工具会话；界面用“新增成员/删除成员”替代“收编/删册”。原生聊天仍在原生工具中进行。
- 所有修改从所属资源列表发起，详情只读；弹层绑定当前连接、完整星/机器/成员/凭证身份。明确星的列表直接提供发节点钥、发管理钥、撤销凭证，不强迫跳转凭证列表。
- k9s 风格：黑底、黄标签、青色按键、白色主表格、浅色选中行。顶栏连接/目标/角色、关键资源动作及紧凑 CC ASCII logo；底部资源标签和 `:资源 /筛选 Esc返回 q退出`。
- 顶栏常显优先级最高的 6–8 项，保留 ? 完整帮助；移动/分页等通用键收进帮助。按键统一 d详情/e修改/Ctrl+D删除/l日志，合理专属键保留。提示与帮助由同一资源声明生成，不再拼接全部按键后整行裁掉。
- 列和标签按终端显示格限制长度，完整值进入详情。命令补全与资源筛选保留。窄屏 logo 先让位于目标、角色和操作。
- star 所有视图固定显示 Broker 管理者/星管理员/普通成员，以及核验状态和时间。配置身份、历史缓存与当前已核验权限明确区分。

## TCP 已批准的新能力

- 2026-10-26 补充：TUI 可将当前星指定 node 的具体原生会话永久入星，固定完整身份、执行端重核、册位及路由实时生效；成员/会话/节点活动页每2秒有界刷新。成员/会话 e 按逐操作原生能力核验，不支持则禁用；未注册工具默认不支持，来源恢复只读重核、不重放写。原生名称之外不设星内别名。接口与边界以[会话选择及成员管理方案](session-selection-membership-design-20261026.md)和[本轮验证](session-selection-membership-validation-20261026.md)为准。

- 删除节点=原子删除当前星完整机器 ID 的全部已绑定节点钥并立即断开对应连接。确认同一步核对凭证集合与版本；变化拒绝。保留成员记录、原生会话、其他星以及未绑定钥/管理钥。
- 远程改名写入对端当前星条目的 showName，不增加 broker 管理别名。仅 broker 管理者和本星管理员；对端在线才可执行，不排队等上线。
- 对端确认保存及运行时采用新名后才成功；落盘失败明确失败，发出后丢回执为待核实、不自动重发。其他星和全局默认不变。
- 复用既有 brokers[].showName（条目覆盖优先于全局默认）；补全远程写入/生效确认、多钥机器一致性、成员/会话投影、启动/入星回执按星名称全链。节点名参与按名寻址，完整 ID 保持稳定。
- TCP 连接支持导入、新增编辑和移除本机配置；移除连接不等于删远端星或撤钥，不自动起停服务。明确旧服务可能仍使用旧配置，提供服务入口；本机 broker 自登记条目的补建规则须说明。
- 星列表可直接启动/停止所属 broker，复用精确服务确认并列出全部受影响星，不能执行裸 serve --stop 扩大到其他节点守护。

## SSH 已批准的新能力

- 外部 SSH Host 继续只读使用；TUI 创建的受管连接可新增、编辑、删除。字段覆盖名称、目标、用户、端口、现有私钥等常用配置；未知外部配置不改写。
- 支持已有密钥/agent，并增加密码和私钥口令遮蔽输入。秘密仅活动连接内存临时使用，刷新/分页/切资源可复用；真正切换连接、配置变化、关闭连接和退出时清除。仅移动列表光标不算切换连接。不写日志、偏好、配置或普通详情。
- 首次主机展示目标、密钥算法和完整指纹，确认后才保存信任；已知指纹变化拒绝连接并要求人工核查，不自动覆盖。
- 认证、连接、取消、超时和异常释放所有自有辅助进程/监听/管道。SSH 失败保持远端来源，不回落本机。
- 不在远端安装 Codex；本轮开发只用隔离 fixture 和受控本机服务，不重启既有远端验收。
