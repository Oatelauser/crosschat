## 行为合同

1. `cA000` 开始，分配顺序递增；`cA999` 之后是 `cB000`。每机器有效窗口最多 1000 个最近分配的编号；过窗短柄即使仍残留在分片，也报过期，不指向槽位的新持有者。每分片原有 8 槽上限保留。
2. 到 `cZ999` 后不回到 A；仍有效的现存短柄可以复用，需要新柄时回退完整 ref。分配不推进成功会话行/轮次，投递后记账保持 best-effort，失败不重发。
3. 每次分配在现有单机目录锁内，将新柄及最高分配序号原子写入同一会话分片并读回验证。刷新、类型细化和原分片清理不得丢进度。
4. 短柄解析/展示/复制均以相同窗口与歧义规则为准。损坏或无法完整读取编号状态时，不猜进度、不返回短柄；完整 ref 路径保留。只读查询不修复/生成状态。
5. 普通维护不自动重置最高进度；强制清理保持全删语义。重置、外部手动删除最高进度分片和旧版本写回不在连续编号保障内，不做旧版本混用适配。
6. 旧 `c<数字>` 参数明确拒绝并提供接续指引；旧全局连续性文件不再作为读取回退。完整 `mc1_`/`mc2_` 路由能力保留。
