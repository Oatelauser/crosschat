# TUI 工作区与完整按键表

2026-10-23。本表对应当前工作区实现；原批准边界见[工作区规格](tui-workspace-spec.md)，使用说明见[终端界面](../tui.md)。运行时以当前模式的 `?` 帮助和权限核验为准。大小写按键不同，例如 `k` 发节点钥，`K` 发管理钥。

## 常显原则

- 顶栏先保留工作区、完整目标的安全摘要、当前角色和核验状态，随后显示当前资源的关键操作。宽屏显示CC标识，窄屏优先保证目标、角色和操作可辨认。
- 列表常显区优先资源自己的修改、下钻和视图动作，再补详情、刷新；保留 `?` 全部按键入口。根据宽高减少提示，不把全部通用移动键铺满主屏。
- `1/2/3` 合为“成员/节点/会话”一项提示；同一动作的主键常显，别名在完整帮助展开。不可用动作置灰并标记，帮助列原因和下一步。
- 主区为单张资源表，筛选状态独立换行，底部显示资源、行数和读取/跟随状态。列有固定宽度上限，长名称和ID截断；详情及复制保留完整安全原值。
- 详情只读，新增、编辑、删除、日志入口从所属资源列表发起。弹层固定来源连接、完整目标和影响；不能在弹层中悄悄换目标。
- 资源键优先于通用键。TCP列表的 `k` 是发节点钥，不再兼任上移；`↑` 始终可上移。`a`、`Ctrl+D` 的含义随资源变化，不能跨页套用。

## 入口和命令

| 资源 | 范围 | Enter | 其他资源动作 |
|---|---|---|---|
| `:ctx`（`contexts`、`connections`） | 全局只读连接看板 | 本机→local首页；SSH→该连接会话；TCP→该连接星列表 | `d` 连接详情；`y` 复制所选行已登记的完整值；没有a/g/t管理动作 |
| `:local` | 当前本机用户资源首页 | 进入所选资源 | `d` 资源说明；`y` 仅在行提供可复制值时可用 |
| `:ssh` | 外部Host与TUI受管SSH连接 | 所选对端会话 | 连接CRUD、检测和体检见下表 |
| `:tcp` | 本机broker与已配置TCP目标 | 所选连接的星列表 | `a` 本机TCP连接配置；已有有效TCP目标时，直接命令回该目标星列表 |
| `:tcp-targets` | 当前本机用户保存的TCP连接 | 所选星的成员列表 | `a/e/Ctrl+D` 导入、编辑、移除，见下表 |

输入 `:` 同时补全资源命令和筛选当前列表；精确命令或显式选中的候选在Enter后跳转，否则保留文字筛选。`/` 仅筛选，不解释为资源命令。星内直接命令复用当前页面或所选行声明的完整星范围，不靠名称或短ID重猜目标。`Esc` 返回保留原页选择和筛选。

以下按键在资源没有覆盖时适用；资源表列出其专有含义。空列表的选中行操作置灰，读取信息等无须选中目标的操作仍可使用。

## SSH连接与远端资源

| 页面 | 完整资源动作 | 可用条件/范围 |
|---|---|---|
| `:ssh` | `Enter` 会话；`d` 连接详情；`a` 新增；`e` 编辑；`Ctrl+D` 删除；`w` 选择已有对端；`t` 检测；`D` 体检；`g` 配置/回程指引；`y` Host或安全连接地址；`i` 来源信息 | a只新增TUI受管条目；e/Ctrl+D仅对受管条目可用，外部Host只读；刷新清单不连接 |
| SSH检测结果 | `Enter` 全量会话；`D` 体检；`d` 采样详情；`g` 指引；`y` 复制；`i` 读取信息；`t` 重新检测 | t只读单页采样，不证明全量、反向回程或其他用户会话；配置写动作/选择在检测页禁用，Esc回列表 |
| SSH `:sessions` | `t/s/u` 工具/原生状态/匿名；`Enter/d` 详情；`g` 原生指引；`i` 读取信息；`Y` 完整引用；`y` 可核验模板 | 默认含匿名并读完分页；受管连接没有原生Host别名时y模板禁用；a/Ctrl+D/b/o/l不接本机业务，不回落本机 |
| SSH `:doctor` | `r` 重跑；`Enter/d` 检查详情；`y` 远端处理指引；`i` 读取信息 | 当前连接同一远端用户执行doctor --json；接口不支持则提示升级，不降级文本或改查本机 |

受管配置独立写 `~/.crosschat/ssh-connections.json`，字段为名称、主机、用户名（可选）、端口、私钥文件（可选）。外部清单只枚举用户SSH配置中明确Host，不展开通配/Include/系统来源为额外列表项；实际OpenSSH连接继续解释其配置。配置变更先绑定完整目标和文件版本，成功后刷新真实连接来源。

密码与私钥口令只在当前活动连接内存复用；切换、关闭、配置变化或退出清除。首次完整指纹需明确确认，已知指纹变化拒绝且不能绕过；不把未知yes/no提示当作可信指纹。结构化远端数据与本机ASKPASS认证分开，不保存秘密到受管配置、普通详情、偏好、argv或环境变量。原生SSH agent等外部认证来源仍归OpenSSH管理。

原生聊天、恢复和终端登录仍由原生工具完成，TUI不托管交互聊天终端，不代表原生会话发送。受管目标是TUI内部连接，不伪造CLI `--via ssh:Host` 别名。

## TCP星资源

“节点”是星内机器；“成员”是持久会话册位。成员在线/下线、机器连接和原生忙闲分列，不互相推断。星Enter默认成员；在星内成员、节点、会话、凭证页面，`1`成员、`2`节点、`3`全星完整发现会话。3不沿用节点限制；节点Enter才进入所选机器的会话范围。

| 页面 | 完整资源动作 | 可用条件/范围 |
|---|---|---|
| `:stars`（`star`） | `Enter` 成员；`d` 详情；`a` 加星；`e` 星名；`Ctrl+D` 删星；`k` 节点钥；`K` 管理钥；`x` 撤凭证；`p` 凭证表；`l` 管理审计；`y` 完整starId；`i` 读取信息；`B` 启动broker；`Ctrl+B` 停止broker | 本机列托管星，远端只列绑定星。星增删改、管理钥发吊、broker起停仅本机Broker管理者；远端审计/起停灰显 |
| `:members`（`roster`） | `Enter/d` 册位详情；`1/2/3` 视图；`a` 选择会话入星；`e` 原生改名；`Ctrl+D` 删除成员；`k/K/x` 发节点钥/管理钥/撤凭证；`t/u/s` 工具/匿名/星籍；`y` 可核验成员地址；`i` 读取信息 | a导航到当前星可发现会话，再选具体 node 行入星；e需实际原生能力；Ctrl+D只删除精确册位；持久离线成员仍可查看；钥匙按角色置灰 |
| `:machines`（`nodes`） | `Enter` 节点会话；`d` 机器详情；`1/2/3` 视图；`v` 全星会话；`k/a` 发节点钥；`K` 管理钥；`x` 撤凭证；`e` 修改本星节点名；`Ctrl+D` 删除节点；`m` 成员；`p` 凭证；`l` 日志可用性；`y` 完整机器ID；`i` 读取信息 | Ctrl+D是原子删除所选机器全部绑定节点钥，x是单凭证撤销；e仅在线节点，空值清本星覆盖；l没有TCP远端日志接口时禁用 |
| TCP全星 `:sessions` | `Enter` 所属节点会话；`d` 会话详情；`1/2/3` 视图；`v` 节点表；`b` 册内/完整发现；`t/u/s` 工具/匿名/原生状态；`a` 所选节点会话入星；`e` 按原生能力改名；`Ctrl+D` 删除成员；`k/K/x` 发节点钥/管理钥/撤凭证；`g` 原生/寻址指引；`y` 可核验地址；`Y` 完整引用；`i` 读取信息；`o/l` 投递/日志可用性 | 默认完整发现，含匿名和未入册会话，每行显示所属机器；a固定完整节点/工具/原生ID，e仅在原生能力核实后开放；不能验证本机通信对关联时o禁用；无TCP远端日志接口时l禁用 |
| TCP节点 `:sessions` | 与全星会话相同，`Enter/d` 改为只读会话详情 | 固定完整机器ID；b保留该机器范围；1/2/3切回星级视图 |
| `:keys`（`credentials`、`node-keys`） | `Enter/d` 安全元数据；`1/2/3` 视图；`k/a` 节点钥；`K/A` 管理钥；`x/Ctrl+D` 撤所选凭证；`y` label；`i` 读取信息 | 列表不返回秘密；完整凭证ID和版本定位，不靠label或mid8；管理钥不冒充节点机器 |

星、成员、节点、会话列表的k/K/x直接打开当前星动作，不强迫进入keys。弹层固定完整starId，节点撤销还固定完整machineId范围；撤销时明确选择完整凭证及其版本。没有选中行的星内发钥沿用页面已固定星，星列表则须选择星。

角色固定显示 `Broker 管理者 / 星管理员 / 普通成员`，认证状态单独显示。配置提示、正在核验、上次结果和已核验结果分清；切星清除旧权限。星管理员可发/撤节点钥、删整机接入、修改在线节点本星名；普通成员保留本星只读与既有成员册操作。UI灰显后，执行端仍独立鉴权。

删星核对完整影响与名称确认；整机删除在同一步核对全部绑定凭证集合，不能只删一把后谎报整机已移除。撤权断开对应既有连接，保留原生会话和永久册位。节点e经对端保存并运行生效才返回完成，清空仅回落对端全局名，不修改全局或其他星；离线没有虚假成功路径。

B/Ctrl+B操作当前星所属的整个broker，确认包含精确服务ID、进程版本和全部托管星影响，变化则重新确认；不把它理解为只起停所选星，也不使用模糊裸停止命令。远端不能借用本机服务权限。

节点、成员、TCP会话表每两秒有界只读刷新；发现每批最多3节点并发，能力只探测当前行。详情、帮助、输入、表单和秘密结果暂停轮询。缓存、部分结果、未知活性和来源失败明确显示，i在空列表仍可查看原因，不把不可达当作空星。TCP会话页 a 将所选 node 的完整会话入星，e 仅按已核实原生能力开放；Codex CLI 已接入，Claude 活窗口同步未核实、Desktop 当前协同端点无改名入口，保持禁用。具体版本和证据见[原生改名验证](native-rename-validation-20261027.md)。
