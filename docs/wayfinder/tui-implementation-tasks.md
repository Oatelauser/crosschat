## 执行与删除约定

用户要求：写/改代码时同步优化规范；任务完成之后删除任务。

- 本文只维护本轮未完成任务，状态为待执行/进行中/待确认/待验收；完成后不留打勾或closed条目。
- 每项任务注明模块、保留的原行为、批准的功能变化、验收和证据。相关记录由提交/PR或独立验收文档保留。
- 验收通过后删除该任务的表格行、说明段落以及排期引用；从剩余任务依赖中移除已满足的ID，重新计算就绪项。
- 最后一个任务验收后删除本清单及map入口；长期规范、设计、审查和验收事实继续保留。
- 待确认、未完成或缺必需实测的任务不得提前删除。取消或缩减范围需有用户明确决定。
- 既有功能变化先完成可审阅方案，等待用户同意后实施相关部分；无依赖工作继续。已确认的TUI需求不重复审批。
- 沿用当前npm单包，产品代码在 `src/tui/` 独立模块，现有CLI与TUI共用应用接口。

### T02 · 解耦配置与选择器

- 将NodeConfig/BrokerEntry、纯读取/归一、星选择器移到不依赖命令或NodeClient的模块，迁移相关导入。
- 消除send/node/via-tcp和serve/session-star两组运行时导入环；保留必要旧导出兼容。
- 验收：导入图门禁区分类型/值边，两组环消失且无新增环；CLI行为与测试保持。

### T03 · 查询与诊断

- 提取会话/星/服务状态/文件/日志的结构化读取；doctor的检查、判定和文本分离。
- 查询区分缺失、损坏、空、失败、过期和部分结果；异步/隔离阻塞探测，支持取消和迟到结果隔离。
- 新纯reader不触发status补投、.bak恢复或其他写入；旧CLI行为保持。
- 验收：查询与诊断行为测试、读取无副作用、取消释放、分页完整性，原输出/判定/退出码不变。

### T04 · 管理与维护应用接口

- 提取typed管理请求/结果，保留热/冷/失败策略；改名不借用含启动语义的整个runServe入口。
- 服务起停有启动中/就绪/失败状态；维护将clean拆为同规则的plan/execute。
- 验收：热写失败不直写、权限拒绝、目标稳定、清理预览不删除、旧管理与清理规则保持。

### T05 · 扩展模型

- 本阶段建立纯核心Provider/Context读取契约与会话模型，含provider+native引用+上下文、匿名名、raw状态、能力、分页/错误/采样时间。UI Resource/Action与快捷键登记由T06负责，等待用户确认后实施。
- Claude/Codex走真实读取Adapter，为TUI全量增加内部查询路径，保持旧调用者默认范围。
- 为成员活性等差异定义明确能力接口，实际聚合器迁移由T13验收。
- 验收：第三测试Provider无需修改通用列表/详情/筛选；同ID不同工具不覆盖；未知状态、21/100条及中途失败正确。
- 本任务不改变旧ref/册/wire，也不等同真实接入OpenCode/zcode；这些真实接入后续单独立项。

### T06 · 全局交互

- ctx默认入口；命令补全与当前资源筛选并存；Enter行为明确；统一短列、中文<raw>、只读详情和完整帮助。
- 对应列表发起操作弹层，固定目标、错误保留输入、成功/返回恢复选中与筛选。
- UI框架封装在展示层；可先以固定数据验证交互，真实资源仅在所需应用接口验收后接入。
- crosschat tui按需加载并保持单包构建/发布；普通CLI不加载框架或监听输入。
- Ctrl+C/异常/退出恢复终端，释放timer/socket/子进程/输入监听；非TTY合理退出，已发写操作取消不伪装回滚。
- 验收：键盘、中文/emoji/长字段、窄终端、resize、返回、输入不误触、终端恢复与普通命令回归。

### T07 · 本机会话

- 默认包含匿名；动态工具/状态筛选；全量分页、稳定选择、完整详情/复制和原生命令指引。
- 适用的收编/删册从列表发起；原生聊天与生命周期仍归原生工具。
- 验收：匿名跨页、工具不可用局部降级、短标识精度、刷新不漂移、详情无写入口。

### T08 · 本机观察资源

- status、doctor、deliveries、outbox、logs统一交互，错误/状态按来源表达。
- 日志有界跟随、暂停、筛选、轮转重开和完整行详情；投递元数据不作为任务完成或原生聊天历史。
- 验收：无自动补投/修复、每资源完整按键、局部失败、长行、轮转、按需体检不阻塞输入。

### T09 · 本机操作资源

- 服务起停和日志、文件元数据、维护清理与技能更新从对应列表进入，任务式预填目标和范围。
- 预览确认、真实就绪/完成状态、失败输入保留；卸载结果准确区分数据和npm包。
- 验收：安全预览、起停影响范围、旧保留规则、权限与失败结果；仅对真实支持的动作开放。

### T10 · SSH

### T11 · TCP浏览

- 有界并发、逐节点错误、旧端/离线部分结果；完整发现依赖D01决策和实现。
- 验收：视图切换/返回、匿名、下线、接任、长名称、单源失败不清空其他结果、无虚假原生忙闲。

### T12 · TCP管理

### T13 · 投递与成员对账解耦

- 将发送核心返回值与CLI formatter分离，TCP桥直接使用typed receipt，不再解析runSend的JSON输出。

- 此任务可与结构化查询、管理服务和TUI外壳并行，交付前独立验收，不把原生聊天加入TUI。

## 每项任务共同的完成条件

1. 达到对应验收，遵守代码规范，相关文档与错误说明准确。
2. 变更范围内有意义测试通过，再跑一次npm run check；新失败或新修改才重复扩大检查。
3. 没有未经确认改变既有功能；没有把部分/旧端能力声称完整。
4. 证据记录到提交/PR或独立验收文档，见核心改造续接记录。
5. 从本清单删除已验收任务及所有活动引用，更新剩余依赖与下一批，不保留已完成条目。
