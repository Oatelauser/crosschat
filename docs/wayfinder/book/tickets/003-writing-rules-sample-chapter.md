## Question

「去废话、别人能懂、章节不乱」怎么落成**可执行的写作规范**？+ 按规范写一篇**样板章**供用户验收定调。

- 规范要可检查：句式红线（禁 AI 废话/主观最高级）、每章结构模板、命令实录格式、代码块注释密度——从 map Notes 已有约束细化为逐条 checklist
- emoji 角色标识词表：机器人/用户（🤖/👤 类）等全书统一符号定调——对话实录一看符号知角色（2026-10-15 用户加规）；**首件定调**（2026-10-16 第2课落地）：🤖=agent、👤=你/用户、📨=agent 收到的外来消息（信封）；**辅助符号**（2026-10-16 用户加规「能用都补上」，第2课 e94b20b 定调）：⚠️=警告/翻车点、✅=判据/通过、❌=失败实录/禁止——扫读定位用，密度随内容
- **emoji 铁边界**（第2课专家提出、即入规范）：emoji 只进散文引导句与表格单元格，**终端实录块内一律不加**——铁边界禁的是**人为往实录里添加** emoji；**程序自身输出的符号**（doctor 的 ✅⚠️、信封里的 📨）是真实输出字节，照抄即得、不在禁区。**图内裁定**（2026-10-16 文档book 验收第1课时定）：ASCII 图示块内**允许角色三件套 🤖👤📨**（图例性质，正合「一看符号即辨」初衷），⚠️✅❌ 仍限散文与表格
- **章节引用可点击（2026-10-16 用户铁律）**：正文提到他章一律相对路径 md 链接，不许裸文字「见 2.5」。式样——同课小节 `[2.5 通信机制](05-mechanism.md)`；跨课 `[第3课 跨机通信（tcp）](../lesson-3.md)`；跨部 `[如何使用反向隧道](../../howto/nat-tunnel.md)`；带锚点加 `#锚`。链接文字 = 章节号+短题
- **两级目录确认制（2026-10-16 用户铁律）**：任何模块开写前，目录（TOC 级课题+小节）与子目录（每节页内 ## 子标题树）都必须经用户逐级确认——标题对齐上报时必须附完整子标题树，缺子目录级不准下发写作任务书
- **表格管道纪律（2026-10-17 U2/U3 验收教训）**：markdown 表格内出现的一切 `|`（**包括反引号代码 span 内的**，如 `a | b` 命令管道、字符集列表）一律转义为 `\|`——GFM 表格按裸管道劈列，反引号不豁免；验收必查每行列数齐整
- 图示规范（**2026-10-16 升格铁律**）：该模块的**关键流程图/架构图必配**——核心流程与架构不许只有文字；ASCII 线框图放 text 块为已定调渲染方式（第2课三图为样板：拓扑图/五步链路图/mc2 布局图）。emoji 词表同为期必（角色 🤖👤📨 + 辅助 ⚠️✅❌，实录块内不加）。「图示优先，一图胜千言」（2026-10-15 用户加规）随之由偏好升为硬性
- 样板章推荐第 1 课（第一课终点章）：用户验收获「就是这个味」的定调结论，后续章节以此为准绳
- 002 七轮修订沉淀的硬规则（2026-10-16，必入规范）：
  - **命令三段式**——干什么用 → 完整实录（看得见的输出）→ 执行时隐式发生什么（一段就地讲完）；命令为主、效果为辅，绝不倒置，效果不独立成节
  - **标题纪律**——零形容词、零内容注释括号（同名区分词除外）、小节带编号；双题制：侧栏短题、章首 H1 长题
  - **每课固定件**——开头「学完这课你能做到」清单＋前置；课末「一句话记住」；实操小节学一步验一步
  - **机制讲法**——先「不用它会怎样」再讲它是什么；类比必带边界（Infra 书手法）
  - **真实事故取材** `docs/drill-reports/`（tcp 课、原理部；不编造示例）
  - tcp 课 3.3 命令一览＝每条一句话的概要地图；全量细节住第三部「命令总表」
- 旧文档冻结口径确认：重造期间旧 docs 只读不投入；对应章写完验收后是否即刻删旧文档（还是书成一刀删）
- 图外节奏确认：一文件一验收、验收过再下一章（用户 Step 3 流程落到会话口令）

## 预算与停止条件

- 一次会话产出规范文档 + 一篇样板章。
- 停止条件：用户对样板章明确点头，规范文档入 main。
