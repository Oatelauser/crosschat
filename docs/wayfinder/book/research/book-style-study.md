## 一、三本书扒到的手法

### 1.《深入理解 AI Infra》（bojieli，mkdocs-material）

- 章名：2–5 字纯名词（模型架构 / 加速器架构 / 训练系统），零修饰
- 首页**十二章导读表**：章 | 主题 | 主要问题——每章绑定一个要回答的问题（「一次生成需要多少显存、计算和数据读写？」）
- 前言手法（作者自己交代的）：
  - **类比必带边界**：大楼与厕所比存储层次，随即点出代价（每层建厕所占面积 = 缓存占片上资源）
  - **一条贯穿线索**：数据搬移五问——搬什么、搬多少、搬几次、经过哪里、谁必须等它；每层设计都回到五问
  - **方法论一句话**：从约束推导设计——先列约束排除不可能，再谈方案
  - **亲历叙事**：用真实经历（FPGA 加速、万卡互联、创业降延迟 5s→500ms）讲设计动机，不编故事

### 2.《亲手造一个 Agent Harness》（papertok，21 章）

- 章名：短主标＋冒号＋具体钩子——「一次工具调用要过七道关」「权限：只许说不，不许说是」
- 小节名：动作/场景句——「先说清楚：没有 agent 的时候，人是怎么干活的」
- 章节**成组打标签**：起步 / Cordis / 循环 / 工具 / 规模 / 读懂之后
- 每章固定件：一句话导语 →「学完这章你能做到」清单 → 前置 → 各节（含「不用它会怎样」「打个比方＋类比失效处」「常见误解」）→「一句话记住」→ 答辩式自测 → 本章小结
- **证据分级**三档标注：仓库明文 / 作者设计意图 / 本站推断

### 3.《小傅哥 AI Agent 通识教程》（xiaofuge，29 章）

- **双题制**：正文长题「主题：一句人话」（「你的第一个 Agent：天气查询助手」），侧栏导航短题（「天气助手」）
- 主线：第 0 章能力全景 → 概念 2 章 → **第 3 章立刻上手做第一个** → 机制逐个拆（ReAct/记忆/运行时）→ 能力面（RAG/FC/MCP/Skills）→ 工程化（评估/安全/部署）→ 展望
- 每章配自测题（全书 508 道），动画拆解概念

### 共通原则（反 AI 味的根）

1. 章名零形容词——信息要么是名词，要么是具体事实/问题
2. 每章绑定一个要回答的问题，导读表呈现
3. 前三章内必须让读者亲手跑通一个最小实例
4. 一条贯穿线索，每章回到它
5. 类比必带边界；机制先讲「不用它会怎样」再讲它是什么
6. 真实经历/事故 > 编造示例
