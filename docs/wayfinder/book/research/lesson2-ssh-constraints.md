## 内容约束（专家判定 + 补遗 7 条，写稿时全量随行）

2.1/课题：双向可达=默认前提，NAT 单向=差量场景（含场景路由入口）。
2.2：术语至少 8 词（Host 别名/hostname/mid(mid8)/origin/ref(mc2_)/短柄 cN/回执三态/[via host]）；「别名=hostname 是回程软依赖、非硬校验」必须原样保留；同名机器场景（mid 不同照样路由+「⚠ 两台机器同名」警告）进 2.5 同机判定或 mid 术语处。
2.4：实录含成功三态+至少一条 [via] 错误实录；命令清单四条定界（发起/照抄 hint 回信免 --via/ssh 对端 crosschat status 查名单别赌名/超限→scp 三步）；status --conversations 本机跨机段对账附注；stdin 引号免疫就顺讲；阈值数字体系就地一段（16KiB→提额→端点硬顶 claude 64KiB/codex 1MiB→ssh 出发前 1MiB 预检，2.5 不重复）；跨机轮次纪律注记（防乒乓单机记账、turn 是跨机唯一防线）；回执机器段形态 名@name(mid8)。
2.5：装七项——固定远端命令面（可配=注入面）/双超时（外层 120s 可调+ConnectTimeout=10+BatchMode）/错误三层映射（同码透传匹配 **stderr** 的 crosschat: CODE 结构）/origin 注入与在场即权威/回程自动选路三分支/mc2 自包含路由/同机判定（mid 决定、hostname 兜底）。

三条勘误红线（旧文档错，书稿不得复刻）：① 远端命令无 `--body -`，stdin 是隐式行为；② 同码透传匹配 stderr 不是 stdout；③ scp 非内建通道（1MiB 预检+报错教三步配方，执行者是 agent/人）。

隐藏细节不得删到失真：--origin 隐藏旗标与在场即权威；完整 id 才可路由、显示名只给人看；别名=hostname 软依赖；柄分配写不推进会话线；normalizeMid 只在比对边界。

归属红线：反向隧道/sshd PATH/scp=环境与 ssh 的能力非 crosschat 代码功能；--file 分块通道是 tcp 的不进 ssh 课；host 白名单（C2）与 --to/--conversation 值白名单=命令面注入防线，成对同语境讲（不进 2.3）。

附议（已采纳）：指南「如何使用反向隧道」=操作+三纪律（User 行必写/Port=2222/会话关回信断），2.3 留差量入口；原理「ssh 与 tcp 星怎么选」=正交并存，不写替代关系。

可选（不强制）：零回归设计原则（--via 缺席单机路径字节不变）、伪造信封残险——原理部或安全注记。

技术深度（mc2 字节布局等）：用户授权专家自决（专家建议至少 flags+UUID 裸装+varint 三要点）。
