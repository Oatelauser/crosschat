# proto:3 会话级星成员（成员=会话、显式继承、聚合器复用现有守护）

## Question

星成员从机器粒度升到会话粒度：会话经启动器声明入星（可多星）、对端在星 roster 里直达声明过的会话、换轨接续显式化。源于多轮 grilling（2026-10-14，会话更替发现问题的完整推演，否决记录见 map 与讨论归档）。

## 用户裁定全录（2026-10-14）

1. **成员键 = 会话 ID**（稳定唯一）；名字仅显示/寻址句柄——同名不歧义，/rename 自动跟随（同 id 换名，roster 更新显示）
2. **继承唯一通道 = `--extend-session` 显式声明**（启动器旗标，可带机器限定旧名）；隐式/同名继承取消（消除歧义，一条心智规则）
3. **非成员会话名投递 = 报错**（机器 ambient 会话投递弃用——用户确认的破坏性收紧，随版迁移说明）；"宽松能送达"否决留痕：若未来重开须带护栏（该名星内无成员史/extends 血统 + 信封明示非成员）
4. **寻址 = 机器+会话限定**（`tcp:<星>:<机器>:<会话>` 三段，复用既有限定词语法；跨机重名合法）
5. **载体 = 现有节点守护升格为聚合器**：每（机器,星）仍一条连接（一次握手/心跳/重连/日志，不随会话数增长）；启动器 spawn 会话时经本地 IPC attach（名字+星+extends），退出即 detach；聚合器心跳核验会话活性（认会话不认启动器，孤儿会话成员仍在）；投递走既有 deliverLocal，013 双开守卫直接复用
6. **零新持久文件**：成员/extends 全为活连接派生的内存态
7. **记忆互备原则（用户反提案定案）**：谁的连接史在谁作证——
   - extends 校验四级链：broker 记得→严验；broker 失忆→转问前任所在节点守护（其内存连接史）→严验；守护也失忆→查本机对话分片（名字+星标识的落盘证据，重启不灭）→有史→严验；分片无记录→放行（该名字从没通过 crosschat 聊过=无人会查询=记录无害死字——校验自洽不变量）
   - 聚合器重启恢复三级链：活会话启动器自动重 attach（常态零操作——启动器是第三方记忆，旗标在手原样重声明，含 extends；broker/守护双重启后系统记忆由活声明自动重建）；孤儿→向 broker 拿回成员名单+本地扫描验活→自动找回；孤儿+双失忆（罕见边角）→**收编命令 `crosschat serve --connect <星> --adopt <会话名>`**（收编活进程的 sessionId，不新建进程、保住现场上下文；名错=UNKNOWN+候选、同名=COLLISION 消歧，可与 --extend-session 并用补血统）——且该命令由 status/报错**当场打印**（名字已填），操作者复制即行，零记忆负担、零选择器误挂面
8. **入星 = 经启动器**（`crosschat claude/codex --connect <星>`，可重复多星）；裸会话不入星（规范即门槛，用户既定立场）
9. **resume/命名细节**：resume 保号与否待实测（影响文档措辞，不影响设计——保号则资格自动延续，换号则需一次 extends）
9a. **双活性模型（俯瞰补）**：claude 成员活性=进程存活（死即除名）；codex 成员活性=线程存在（落盘实体，durable 永不自动除名——resume 即复活对 codex 是正确语义；extends 对 codex 几乎不适用）。attach 一律 id 先行、名字从扫描回填（codex 无 -n 是此设计的天然验证）
9b. **老 broker 降级必须显性（俯瞰补）**：新聚合器连老 broker（proto:1）时成员帧被丢弃（未知 op 静默丢）——握手加 caps 协商，broker 不支持 proto:3 时聚合器显性告警"已降级机器级"，禁止静默装死
10. **纯代码链路**：attach/roster/extends 解析/投递/恢复全为 IPC+WS+扫描，零模型调用
11. **status 兼容**：新增星会话视图（机器+会话行，extends 标注），机器视图/E1 原样（additive）
12. **排期**：proto:3 先于 010（用户裁定）；010 的安全敞口多开数日已知悉备案；caps 机制由本票先定、TLS 沿用

## 实施面（继承此前讨论定案）

- 启动链：启动器读 node.json → 确保聚合器（必要时自动拉起）→ spawn 会话 → attach → 聚合器广播成员帧（含 extends）→ broker 内存 roster
- 投递链：对端 `tcp:<星>:<机器>:<会话>` → broker 会话成员解析 → 目标聚合器 → deliverLocal；死名 → extends 链解析（含跨机，broker 全星内存映射）→ 报错指路接任者
- 生命周期链：会话死→扫描除名；改名→id 跟随；broker/聚合器重启→记忆互备三级链
- 兼容：机器级操作（status 枚举/文件通道）不变；唯一破坏=会话名投递收紧（裁定 3，随版迁移说明）

## 预算与停止条件

- 规模 M 票：聚合器 attach IPC + 成员/extends 帧 + broker 会话级 roster 与解析 + 启动器旗标 + status 视图 + 记忆互备两链 + 测试（含真实平台形态夹具）+ 文档/skill 随版
- 停止条件：npm run check 全绿；三机真机验收（win/WSL/cloud）——会话入星/多星并存/直达投递/extends 接任弹错指路/改名跟随/改名接任声明/双端重启自愈链/非成员名报错；机器级流程零回归（除裁定 3 明示收紧）
