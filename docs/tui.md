# 终端界面

使用 `crosschat tui` 启动，需要可输入和输出的交互终端。仓库内运行先执行 `npm run build`，再运行 `node dist/cli.js tui`。

当前版本提供连接入口、本机会话、状态总览、doctor、投递记录、滞留与日志，以及本机服务、文件、维护、SSH远端会话/体检和TCP星/节点/成员/凭证管理。命令补全与筛选、完整发现、只读详情和确认操作共用一致的交互。界面不代替 Claude Code、Codex 等原生聊天。

## 连接与导航

启动停留在 `ctx` 连接列表，仅记忆最近选择，不自动进入或探测远端。SSH列表读取已有别名；TCP列表读取已有节点配置。配置中的身份提示不代表本次连接已经认证。

按上下键或 j/k 选择，Enter进入连接的默认资源，本机/SSH为sessions，TCP为machines；d查看连接详情，Esc返回。界面偏好单独写入 `~/.crosschat/tui.json`，不会更改SSH或节点配置。

ctx的a进入已有连接选择：选择SSH别名，或导入已有TCP配置；g查看配置/执行位置/回程指引，t只检测所选连接：本机读取状态，SSH执行单页采样，TCP认证并读取本星快照。SSH Host已从配置自动包含，不另建连接清单、不编辑SSH配置。

TCP导入接受当前`brokers`数组及完整starId，只追加新星，保留已有字段，不替换同星凭证或迁移旧形状。JSON输入为私密字段；先预览安全目标再确认，成功后重读ctx并选中实际新增项，不自动联网或启动服务。确认后配置变化会拒绝；原子替换前再复核可观测修改，这不等于与无锁旧writer建立跨进程锁。

输入 `:` 进入命令模式，例如 `:sessions`、`:ctx`、`:stars`。输入过程同时补全命令并筛选当前列表的完整原值。Tab/Shift+Tab或上下键选择候选，Enter执行精确命令或选中候选；其余输入保留为当前列表筛选。底部说明本次Enter行为。`/`只筛选当前列表，避免与资源名冲突。Esc撤销输入草稿。

## 按键与显示

每页按 `?` 查看该模式全部按键、不可用原因和下一步。以下是共享操作；各资源的专有操作也登记在对应列表帮助中。

| 场景 | 按键 | 行为 |
|---|---|---|
| 列表 | ↑/↓、j/k、PgUp/PgDn、Home/End | 移动选择 |
| 列表 | r、S | 刷新、切换排序字段；日志保持原始顺序 |
| 列表 | Enter/d、y | 下钻或只读详情、复制完整值；以当前页帮助为准 |
| 列表 | Esc | 先清文字筛选，再清资源筛选，再返回并恢复位置 |
| 详情 | ↑/↓、j/k、PgUp/PgDn、Home/End、/、y | 滚动、查找、复制当前字段完整原值 |
| 帮助 | ↑/↓、j/k、PgUp/PgDn、Home/End、Esc/? | 滚动全部说明、关闭 |
| 表单 | Tab/Shift+Tab、Enter、Esc/Ctrl+C | 切字段/按钮、执行选中按钮、取消 |
| 表单 | PgUp/PgDn；按钮聚焦时Home/End | 完整滚动连接、目标、影响清单及错误说明 |
| 全局 | Ctrl+C | 有读取时取消，否则退出；表单内取消表单 |

列宽按终端显示格限制，中文、emoji和组合字符保持完整；窗口变窄时隐藏次要列。详情换行滚动，复制保留原值。原生状态显示中文加原值，例如 `空闲<idle>`，未知状态也保留原值。

## 本机会话

从本机连接进入 `sessions`，默认显示所有当前来源可发现的非归档会话，包括匿名会话。每个工具沿分页读取到结束后整体更新列表；读取期间保留原列表。来源错误、取消和部分结果会明确标记，按 `i` 查看完整读取信息和下一步。不会自动补投、修复配置或恢复原生会话。

| 按键 | 行为 |
|---|---|
| t / s | 选择工具 / 原生状态；选项来自已登记来源及实际数据 |
| u | 切换所有会话（含匿名）与仅命名会话 |
| b | 会话范围；本机页无星范围，说明不可用原因 |
| Enter / d | 查看完整安全元数据、原始状态、完整引用和采样时间 |
| g / i | 原生工具操作指引 / 本次读取信息；读取信息允许空列表查看 |
| y / Y | 复制当前可确认的完整发送地址 / 完整 SessionRef |
| a / Ctrl+D | 收编已有会话 / 删除所选星册位，从列表发起并确认 |
| o / l | 按完整本机会话引用查看相关投递 / 日志；无可验证关联时说明原因 |

工具和状态选择器支持上下键、j/k、Tab/Shift+Tab、PgUp/PgDn、Home/End；Enter应用，Esc撤销，d查看完整选项，y复制完整选项值，?查看该模式帮助。文字筛选与这些筛选独立，返回页面时保留。

地址与引用有不同用途：`y`遵守现有本机发送选择器，重名、名称前缀冲突、不完整来源或超出 Codex 默认20条选择范围时禁用；`Y`仍可复制完整引用。地址只代表当前采样，不保证稍后发送成功。原生指引只展示操作方式，不启动聊天或代表会话发送消息。

册位表单明确选择已配置星；单个可用星自动带入，多个星必须选择。确认中列出完整星、机器、工具、会话身份和可能启动聚合器的影响。收编重新核对本机发现与实际聚合器身份，并以所选星册确认结果；删册由 broker 原子核对完整会话 ID、机器和工具，目标变化即拒绝。两者均不终止或删除原生会话，原 CLI 名字/前缀选择行为保持。

## 本机观察资源

先在 `ctx` 选择本机，再输入资源命令。以下页面共用 `:` 补全、`/` 筛选、`r` 刷新、`?` 完整帮助、`d` 详情和 `i` 读取信息；`i` 在空列表也可用。列表只显示限宽字段，详情和复制保留完整安全值。

| 页面 | 内容 | 专有按键与复制值 |
|---|---|---|
| `:status` | 会话来源、SSH配置、TCP配置、服务快照、发件箱/看门狗、本次TUI最近体检六项 | Enter进入对应资源；y复制选中状态 |
| `:doctor` | 现有诊断的逐项结果、原始级别、解释与处理指引 | 进入或r运行一次；y复制选中指引，执行由用户决定 |
| `:deliveries` | 本机已有通信对、通道、最近记录和传输状态 | w相关滞留；l相关投递日志；y仅复制已保存且可验证的完整续话引用 |
| `:outbox` | 各目标线程的暂存条数、时间、状态与镜像路径 | o相关通信对，无法核实单一通信对时禁用；y复制镜像路径；l说明没有独立看门狗日志 |
| `:logs` | 已登记本机日志的有界尾窗 | t选来源；Space暂停/恢复；上滚/PgUp/Home暂停，End恢复到最新匹配行；y复制安全日志行；S不可用 |

总览不会自动运行doctor或检测全部远端。配置数不代表已连接或认证；不可读、部分结果和未知数量会分别说明。服务快照显示时效与PID证据；撤权暂停还需匹配当前凭证的撤权记录。总览中的体检缓存仅属于本次TUI。

doctor在独立、可取消的进程中运行，沿用原CLI检查和严重度；按Ctrl+C取消读取，之后可按r重跑。它只显示建议，不自动修复。页面中的TCP检查可能按现有doctor规则探测已配置地址；仅查看status不会发起这些连接。

投递记录是通信对摘要，不是每条消息的完整历史。传输状态、回执和暂存不代表任务完成。读取这些页面不会发送、补投、重试、生成引用或改变队列；正文和凭证不会进入普通详情。坏队列、超过读取上限的队列和不完整审计窗口不会显示成“没有数据”。

相关跳转使用完整引用或通信对标识，Esc恢复来源页的选择和筛选；直接输入资源命令会清除关联范围。日志t切换来源后查看该来源的全部当前尾窗，标题会说明范围变化。名字、短ID或无法确认机器身份的发送方不足以证明本机会话关联。

日志默认每秒跟随一次，单次最多64KiB、最近1000行；超过窗口的内容可在原生终端查看。来源包括投递、broker、会话接入和已发现的节点日志及轮转副本。重复行保留不同字节位置，追加保持原有行身份，文件替换或观察到缩短时重开。超长边缘行片段隐藏并说明；未换行的末行标注为当前已写内容。已知秘密字段和本机IPC能力隐藏后才可查看/复制。

日志筛选为零匹配时仍可跟随。详情、输入、帮助与来源选择期间暂停轮询，返回后按原跟随意图恢复；换资源、换上下文、刷新、取消和退出会释放旧观察。文件若在两次采样间被截断后重新增长到更大，单凭文件身份和长度无法确认这一过程；尾窗始终按当前采样显示。

## 本机服务、文件与维护

| 页面 | 专有按键 | 行为 |
|---|---|---|
| `:services` | a / Ctrl+D | 启动 / 停止所选服务，列表上预览影响并确认 |
| `:services` | Enter或d / l / y / i | 只读详情 / 当前服务日志 / 完整标识 / 读取信息 |
| `:files` | Enter或d / y / m / i | 文件元数据 / 完整路径 / 维护列表 / 读取信息 |
| `:maintenance` | Enter / d / y | 所选任务预览及确认 / 范围与最近实际结果 / 对应说明 |

服务列表包括broker、已配置节点及可观察的孤立进程。进程存在和实际就绪分别显示；启动必须匹配实际活进程、PID、新快照与状态才算就绪。配置/快照不完整时不能假称已停止。同星防双开和broker内挂占用沿用原检查；不能独立起停的内挂聚合器、不能精确对应的裸选择器等会禁用并说明下一步。

停止只针对确认的完整进程集合，同次扫描发现PID变化便拒绝，不把一行操作扩大成停止全部节点。停止服务不撤钥、不删册、不结束原生聊天。取消或超时可能发生在外部停机信号发出后，结果需核实，不能认作回滚；不会自动重试。同步系统探测由可回收的专属进程树执行。

files只读取类别、大小、修改时间和路径，不查看收件正文、凭证或配置内容。维护从四类任务中选择：按原保留规则清理、强制清理、安装/更新skills、卸载本机数据。Enter先列目标和影响，默认取消；提交重算确认指纹，范围变化就拒绝执行。清理保留原5天、容量和30天JSON分片规则，outbox等不在该范围。强制清理也不会顺带清理队列或日志。

技能安装沿用先后次序，前一目标失败即停止后续尝试；损坏/不可读状态、目录链接、会重定向写入的目标硬链接或无法完整核验的范围会阻止TUI操作。执行详情列实际成功、失败和跳过，不把计划数量当成功数量。新尝试结果未知时显示待核实，并区分上次已确认结果。

卸载只执行原有本机数据/技能范围，运行状态不允许时拒绝；不会运行npm卸载。结果明确提示npm包仍在及收尾命令。卸载已发出或结果不明后，本次TUI退出不会重新写偏好、重建已删数据目录。

## SSH对端与远端资源

`:ssh`列已有明确Host别名；Enter进入远机会话，a在已有别名中选择，t检测所选Host，D进入其doctor，g查看配置/回程指引，d只读详情，y复制Host，i查看来源问题。所有页面仍有通用导航/筛选/帮助，启动和刷新SSH清单不批量连接。

SSH会话沿用t/s/u筛选、Enter/d详情、g原生指引、Y完整引用与i读取信息，默认包含匿名并读完分页。y仅在现有寻址规则可核验且命令参数安全时复制发送模板，供当前用户自行核对并补正文；不冒用所选会话发言。本机册位、投递记录和日志关联在远端页禁用，不会误读本机作为替代。

SSH发现和体检均由所选Host当前配置决定的远端用户执行。doctor使用本轮新增的 `crosschat doctor --json`，逐项显示与本机一致的检查/级别，并标明远端处理位置；退出1但结构结果有效代表体检完成且存在错误。无参doctor保持原文本、检查与退出码。不支持新接口时提示在同一远端用户环境升级，无旧文本降级。

分页游标额外绑定本次观察到的SSH配置文件内容；读取期间该文件变化会拒绝续页，按r从第一页重读。此绑定不声称钉住已认证UID，也不追踪Include等间接配置文件的版本。t是单页采样，不代表全量发现完成或反向回程已通。

固定argv、BatchMode、输出限额、超时和取消保护远端读取；认证、主机身份、PATH、接口、超时和损坏数据都有安全下一步，不展示原始秘密错误、不改用本机。显式隔离HOME时还为SSH命令绑定该目录的配置文件；这不代表所有密钥、agent、known_hosts或配置中引用的其他路径都被隔离。普通自动测试注入SSH子进程，不连接真实对端。

## TCP星、节点、会话与管理

本机`:stars`列本机broker托管星；TCP连接只显示当前绑定星，不能枚举远端其他星。SSH未提供管理接口时说明不可用，不会改用本机管理。配置权限提示与本次认证分开，顶部显示实际读取权限和采样时间。

| 页面 | 专有按键 | 行为 |
|---|---|---|
| `:stars` | Enter / d / a / e / Ctrl+D | 进入节点 / 只读详情 / 加星 / 改星名 / 删星 |
| `:stars` | p / l / y / i | 凭证 / 本机该星管理审计 / 完整starId / 读取信息 |
| `:machines`（别名nodes） | Enter / d / v | 节点会话 / 只读机器详情 / 全星会话 |
| `:machines` | a / e / Ctrl+D | 让新机器接入 / 当前本机显示名（全局或本星）/ 精确撤节点 |
| `:machines` | m / p / l / y / i | 成员册 / 凭证 / 节点日志可用性 / 完整机器ID / 读取信息 |
| `:members` | Enter或d / a / Ctrl+D | 只读册位 / 选本机已有会话收编 / 只删所选册位 |
| `:members` | t / u / s / y / i | 工具 / 匿名 / 星籍筛选 / 可核验地址 / 读取信息 |
| `:keys`（别名credentials、node-keys） | Enter或d / a / A / Ctrl+D / y / i | 安全元数据 / 发节点配置 / 发星管理钥 / 撤凭证 / label / 读取信息 |
| TCP `:sessions` | 全星Enter / d；节点Enter或d | 下钻所属节点 / 只读会话；节点页查看会话详情 |
| TCP `:sessions` | v / b / t / u / s / a / Ctrl+D | 节点表 / 册内与完整发现范围 / 工具 / 匿名 / 原生状态 / 本机收编 / 删册位 |
| TCP `:sessions` | g / y / Y / i / o / l | 原生指引 / 可核验地址 / 完整引用 / 读取信息 / 投递与日志可用性 |

机器表只列已绑定的机器，凭证另列未使用节点钥和管理钥。相同mid8仍按完整机器ID区分；节点名称不是唯一身份。成员册在线/下线与机器连接、原生忙闲分别显示，未进行原生发现时不推断idle。

星默认节点列表，v切全星会话；默认范围为册内成员，b才读取节点可发现的非归档会话，包括未入册与匿名会话。每行保留所属节点，Enter下钻；按最多三节点并发读完分页，离线/单源错误保留部分结果，Esc返回保留选择和筛选。完整发现手动刷新，不在后台反复扫描原生会话。

机器列表每两秒刷新一次只读快照，保留当前选择，实际绑定/上线后才显示机器；详情、输入、帮助、确认和秘密结果期间暂停，离开释放旧查询。Ctrl+C可暂停，r恢复。该快照不记录管理审计；原list-nodes/list-members审计保持。

所有写动作先预览并重新核对。删星列完整静态影响并要求名称确认；删除使用确认版本，在broker或冷事务同一步核验。凭证替换、label复用、机器绑定变化或删星影响新增都会拒绝；不回落其他选择器，不自动重试。撤钥立即使相应既有连接失效，保留原生聊天与永久册位。多把钥匙绑定同机时，机器页不会把单次撤钥冒充移除整机，需到keys逐把确认。

新机器接入默认一份配置，需填接收机可达地址，不默默把localhost或监听通配地址当远机地址。配置已生成与机器已上线分别显示。一次性结果页按登记键复制各份配置，c复制连接指引；Esc/Ctrl+C隐藏秘密并清当前画面后返回，q清除后退出，不再次提交生成。秘密不进入普通列表、详情、偏好或错误；OS剪贴板和外部终端录像需用户自行处理。

星增删改和发吊管理钥仅broker本机；星管理员可发节点钥/撤节点，普通成员仅本星读取与既有册位操作。当前本机显示名只修改本机配置，区分全局默认、本星覆盖与实际连接生效；远机无改名/日志接口时给出切对应SSH的指引。删册不删原生会话，收编只能选择本机完整引用，不冒用远机会话身份。

管理审计沿用原动作/频率，新增完整starId作用域，按稳定身份筛选。全局显示名一次动作记录所有受影响星。旧行无完整标识时明确无法准确归属，不按相同星名混入当前星；日志仍受有界尾窗限制。

## 操作与退出（通用）

修改动作从所属资源列表发起。共享表单固定连接和目标，检查权限与影响后确认，默认选中取消；确认前再次核验，期间显示核验状态。长影响和错误说明可完整滚动，标题与取消/确认按钮始终保留。失败保留输入。表单编辑至少需要24列×16行，窗口不足时暂停编辑，放大后继续或Esc取消。

写请求发出后取消仅停止等待，显示结果待核实，不表示回滚，也不会自动重发；未确认的写入应先核实目标星册。

正常退出、Ctrl+C和异常退出会清理自有读取/监听/子进程，并恢复raw模式、光标、括号粘贴与主屏。非交互终端在读取配置和加载界面框架前退出。

## 结构与验证

`src/tui/`的展示只依赖controller快照。资源、列、动作和帮助共用登记；业务由可取消的Adapter提供，新Provider原生差异留在应用适配层。终端框架仅在 `tui` 命令动态加载。

执行 `npm run check` 验证规范、依赖方向、构建和隔离测试。Windows真实终端验收另运行 `node test/helpers/tui-pty-validation.mjs`（外壳）、`node test/helpers/tui-sessions-pty-validation.mjs`（本机会话）、`node test/helpers/tui-observations-pty-validation.mjs`（观察）、`node test/helpers/tui-operations-ssh-pty-validation.mjs`（操作/SSH）与 `node test/helpers/tui-tcp-pty-validation.mjs`（TCP）。工装使用ConPTY、临时HOME、受控文件和注入的原生来源/剪贴板/操作接口；不访问真实会话、起停真实服务或连接远端。实际证据见[开发与验收记录](development/tui-progress.md)。
