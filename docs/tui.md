# 终端界面

使用 `crosschat tui` 启动，需要可输入和输出的交互终端。仓库内运行先执行 `npm run build`，再运行 `node dist/cli.js tui`。

当前版本提供只读全局看板和独立的本机、SSH、TCP工作区，覆盖会话发现、状态、体检、投递与日志、本机服务和维护、连接配置，以及TCP星/节点/成员/凭证管理。命令补全与筛选、完整发现、只读详情和确认操作共用一致的交互。界面不代替 Claude Code、Codex 等原生聊天，也不代表所选原生会话发言。

## 连接与导航

启动停留在 `ctx` 全局只读看板，仅记忆最近选择，不自动进入或探测远端。看板汇集本机、已有SSH Host、TUI受管SSH连接和已配置TCP连接；只提供进入、详情及通用浏览操作，不承担连接增删改、检测或管理动作。配置中的身份提示不代表本次连接已经认证。

Enter进入所选连接：本机先到 `local` 资源首页，再进入会话、状态等列表；SSH进入该连接的会话列表；TCP进入该连接的星列表，选星后默认进入成员列表。d只读详情，Esc返回并恢复来源页位置。界面偏好单独写入 `~/.crosschat/tui.json`；只有在对应工作区明确确认配置操作后才会修改连接配置。

输入 `:local`、`:ssh`、`:tcp` 切换工作区。本机首页列本机资源；SSH入口列对端及其配置操作；TCP入口选择本机broker或已配置远端连接，已有有效目标时回到该目标的星列表，不恢复任意子页面。TCP入口的a进入 `:tcp-targets` 本机连接配置列表。资源内的增删改、详情和日志入口归各自列表，详情保持只读。

`:tcp-targets` 支持导入、编辑和移除本机保存的TCP连接；`:ssh` 支持新增、编辑和删除TUI受管连接。外部SSH Host只读。两类配置操作都先预览目标和影响，再确认；成功后重新读取真实连接清单，不把保存配置当作已认证或服务已上线。

输入 `:` 进入命令模式，例如 `:sessions`、`:ctx`、`:stars`。输入过程同时补全命令并筛选当前列表的完整原值。Tab/Shift+Tab或上下键选择候选，Enter执行精确命令或选中候选；其余输入保留为当前列表筛选。提示说明本次Enter行为。`/`只筛选当前列表，避免与资源名冲突。Esc撤销输入草稿。星内资源跳转沿用当前完整星范围；切换连接时不会把旧星权限或查询结果带给新目标。

## 按键与显示

顶栏左侧显示工作区、目标、角色和核验状态，中部优先提示当前资源的关键操作；宽屏右侧显示CC标识。主区保持一张资源表，底部显示当前资源、行数和读取状态。资源筛选状态独立换行显示。常显区只保留有限数量的关键键和 `?`，随窗口宽度收缩；`1/2/3`合并为一个视图提示，同一动作的别名仅在完整帮助展开。不可用操作置灰，帮助说明原因和下一步。全部模式和逐资源完整键表见[工作区按键表](development/tui-workspace-keys.md)。

以下是共享操作；资源自己的键优先。例如TCP的k用于发节点钥匙，在这些列表用↑上移，不能再把k解释为上移。

## 本机会话

从 `local` 首页进入 `sessions`，默认显示所有当前来源可发现的非归档会话，包括匿名会话。每个工具沿分页读取到结束后整体更新列表；读取期间保留原列表。来源错误、取消和部分结果会明确标记，按 `i` 查看完整读取信息和下一步。不会自动补投、修复配置或恢复原生会话。

| 按键 | 行为 |
|---|---|
| t / s | 选择工具 / 原生状态；选项来自已登记来源及实际数据 |
| u | 切换所有会话（含匿名）与仅命名会话 |
| b | 会话范围；本机页无星范围，说明不可用原因 |
| Enter / d | 查看完整安全元数据、原始状态、完整引用和采样时间 |
| g / i | 原生工具操作指引 / 本次读取信息；读取信息允许空列表查看 |
| y / Y | 复制当前可确认的完整发送地址 / 完整 SessionRef |
| a / Ctrl+D | 收编已有会话 / 删除所选星册位，从列表发起并确认 |
| o / l | 按完整本机会话引用查看相关投递 / 日志；无可验证关联时说明原因 |

工具和状态选择器支持上下键、j/k、Tab/Shift+Tab、PgUp/PgDn、Home/End；Enter应用，Esc撤销，d查看完整选项，y复制完整选项值，?查看该模式帮助。文字筛选与这些筛选独立，返回页面时保留。

地址与引用有不同用途：`y`遵守现有本机发送选择器，重名、名称前缀冲突、不完整来源或超出 Codex 默认20条选择范围时禁用；`Y`仍可复制完整引用。地址只代表当前采样，不保证稍后发送成功。原生指引只展示操作方式，不启动聊天或代表会话发送消息。

册位表单明确选择已配置星；单个可用星自动带入，多个星必须选择。确认中列出完整星、机器、工具、会话身份和可能启动聚合器的影响。收编重新核对本机发现与实际聚合器身份，并以所选星册确认结果；删册由 broker 原子核对完整会话 ID、机器和工具，目标变化即拒绝。两者均不终止或删除原生会话，原 CLI 名字/前缀选择行为保持。

## 本机观察资源

先进入 `:local`，再从首页或资源命令打开列表。以下页面共用 `:` 补全、`/` 筛选、`r` 刷新、`?` 完整帮助、`d` 详情和 `i` 读取信息；`i` 在空列表也可用。列表只显示限宽字段，详情和复制保留完整安全值。

| 页面 | 内容 | 专有按键与复制值 |
|---|---|---|
| `:status` | 会话来源、SSH配置、TCP配置、服务快照、发件箱/看门狗、本次TUI最近体检六项 | Enter进入对应资源；y复制选中状态 |
| `:doctor` | 现有诊断的逐项结果、原始级别、解释与处理指引 | 进入或r运行一次；y复制选中指引，执行由用户决定 |
| `:deliveries` | 本机已有通信对、通道、最近记录和传输状态 | w相关滞留；l相关投递日志；y仅复制已保存且可验证的完整续话引用 |
| `:outbox` | 各目标线程的暂存条数、时间、状态与镜像路径 | o相关通信对，无法核实单一通信对时禁用；y复制镜像路径；l说明没有独立看门狗日志 |
| `:logs` | 已登记本机日志的有界尾窗 | t选来源；Space暂停/恢复；上滚/PgUp/Home暂停，End恢复到最新匹配行；y复制安全日志行；S不可用 |

总览不会自动运行doctor或检测全部远端。配置数不代表已连接或认证；不可读、部分结果和未知数量会分别说明。服务快照显示时效与PID证据；撤权暂停还需匹配当前凭证的撤权记录。总览中的体检缓存仅属于本次TUI。

doctor在独立、可取消的进程中运行，沿用原CLI检查和严重度；按Ctrl+C取消读取，之后可按r重跑。它只显示建议，不自动修复。页面中的TCP检查可能按现有doctor规则探测已配置地址；仅查看status不会发起这些连接。

投递记录是通信对摘要，不是每条消息的完整历史。传输状态、回执和暂存不代表任务完成。读取这些页面不会发送、补投、重试、生成引用或改变队列；正文和凭证不会进入普通详情。坏队列、超过读取上限的队列和不完整审计窗口不会显示成“没有数据”。

相关跳转使用完整引用或通信对标识，Esc恢复来源页的选择和筛选；直接输入资源命令会清除关联范围。日志t切换来源后查看该来源的全部当前尾窗，标题会说明范围变化。名字、短ID或无法确认机器身份的发送方不足以证明本机会话关联。

日志默认每秒跟随一次，单次最多64KiB、最近1000行；超过窗口的内容可在原生终端查看。来源包括投递、broker、会话接入和已发现的节点日志及轮转副本。重复行保留不同字节位置，追加保持原有行身份，文件替换或观察到缩短时重开。超长边缘行片段隐藏并说明；未换行的末行标注为当前已写内容。已知秘密字段和本机IPC能力隐藏后才可查看/复制。

日志筛选为零匹配时仍可跟随。详情、输入、帮助与来源选择期间暂停轮询，返回后按原跟随意图恢复；换资源、换上下文、刷新、取消和退出会释放旧观察。文件若在两次采样间被截断后重新增长到更大，单凭文件身份和长度无法确认这一过程；尾窗始终按当前采样显示。

## 本机服务、文件与维护

| 页面 | 专有按键 | 行为 |
|---|---|---|
| `:services` | a / Ctrl+D | 启动 / 停止所选服务，列表上预览影响并确认 |
| `:services` | Enter或d / l / y / i | 只读详情 / 当前服务日志 / 完整标识 / 读取信息 |
| `:files` | Enter或d / y / m / i | 文件元数据 / 完整路径 / 维护列表 / 读取信息 |
| `:maintenance` | Enter / d / y | 所选任务预览及确认 / 范围与最近实际结果 / 对应说明 |

服务列表包括broker、已配置节点及可观察的孤立进程。进程存在和实际就绪分别显示；启动必须匹配实际活进程、PID、新快照与状态才算就绪。配置/快照不完整时不能假称已停止。同星防双开和broker内挂占用沿用原检查；不能独立起停的内挂聚合器、不能精确对应的裸选择器等会禁用并说明下一步。

停止只针对确认的完整进程集合，同次扫描发现PID变化便拒绝，不把一行操作扩大成停止全部节点。停止服务不撤钥、不删册、不结束原生聊天。取消或超时可能发生在外部停机信号发出后，结果需核实，不能认作回滚；不会自动重试。同步系统探测由可回收的专属进程树执行。

files只读取类别、大小、修改时间和路径，不查看收件正文、凭证或配置内容。维护从四类任务中选择：按原保留规则清理、强制清理、安装/更新skills、卸载本机数据。Enter先列目标和影响，默认取消；提交重算确认指纹，范围变化就拒绝执行。清理保留原5天、容量和30天JSON分片规则，outbox等不在该范围。强制清理也不会顺带清理队列或日志。

技能安装沿用先后次序，前一目标失败即停止后续尝试；损坏/不可读状态、目录链接、会重定向写入的目标硬链接或无法完整核验的范围会阻止TUI操作。执行详情列实际成功、失败和跳过，不把计划数量当成功数量。新尝试结果未知时显示待核实，并区分上次已确认结果。

卸载只执行原有本机数据/技能范围，运行状态不允许时拒绝；不会运行npm卸载。结果明确提示npm包仍在及收尾命令。卸载已发出或结果不明后，本次TUI退出不会重新写偏好、重建已删数据目录。

## SSH对端与远端资源

`:ssh` 同列外部Host与TUI受管连接。Enter进入远机会话，a新增受管连接，e编辑受管连接，Ctrl+D删除受管连接，w从已发现对端中选择，t检测所选目标，D进入其doctor，g查看配置/回程指引，d只读详情，y复制Host或安全连接地址，i查看来源问题。外部Host的编辑和删除置灰。启动、浏览和刷新清单不批量连接。

受管连接保存在当前用户 `~/.crosschat/ssh-connections.json`，可设置名称、主机、用户名、端口和私钥文件路径；不编辑 `~/.ssh/config`，不保存密码或私钥口令。外部清单枚举用户配置中明确的Host别名，不把通配Host、Include或系统配置展开成额外列表项；实际连接仍由OpenSSH解释对应配置。受管连接不是原生Host别名，不能直接作为CLI的 `--via ssh:Host`；原生操作使用详情中的真实主机、用户和端口。

密码及私钥口令以遮蔽输入接收，仅在当前活动连接内存临时复用；切换、关闭连接、配置变化或退出即清除。首次连接需核对OpenSSH给出的算法和完整SHA256指纹，确认默认取消；已知指纹变化直接拒绝，不提供忽略检查入口。信任记录由OpenSSH写入对应known_hosts，取消不会视为已经信任。

SSH会话沿用t/s/u筛选、Enter/d详情、g原生指引、Y完整引用与i读取信息，默认包含匿名并读完分页。外部Host的y仅在现有寻址规则可核验且命令参数安全时复制发送模板，供当前用户自行核对并补正文；受管连接没有对应原生Host别名时禁用此模板，不生成无法执行的命令。本机册位、投递记录和日志关联在远端页禁用，不会误读本机作为替代。

SSH发现和体检均由所选Host当前配置决定的远端用户执行。doctor使用本轮新增的 `crosschat doctor --json`，逐项显示与本机一致的检查/级别，并标明远端处理位置；退出1但结构结果有效代表体检完成且存在错误。无参doctor保持原文本、检查与退出码。不支持新接口时提示在同一远端用户环境升级，无旧文本降级。

分页游标额外绑定本次观察到的连接配置版本；读取期间配置变化会拒绝续页，按r从第一页重读。此绑定不声称钉住已认证UID，也不追踪外部Include等间接配置文件的版本。t是单页采样，不代表全量发现完成或反向回程已通。

远端命令使用固定argv、输出限额、超时和取消保护。TUI通过独立的本机ASKPASS通道接收认证，不占用结构化命令的stdin；未启用交互的应用调用仍为BatchMode。认证、主机身份、PATH、接口、超时和损坏数据都有安全下一步，不展示秘密原文、不改用本机、不在远端自动安装软件。显式隔离HOME时还为SSH命令绑定该目录的配置文件；这不代表所有密钥、agent、known_hosts或配置中引用的其他路径都被隔离。

| TCP `:sessions` | v / b / t / u / s / a / e / Ctrl+D | 节点表 / 册内与完整发现范围 / 工具 / 匿名 / 原生状态 / 所选节点会话入星 / 按原生能力改名 / 删册位 |
| TCP `:sessions` | g / y / Y / i / o / l | 原生指引 / 可核验地址 / 完整引用 / 读取信息 / 投递与日志可用性 |

机器表只列已绑定的机器，凭证另列未使用节点钥和管理钥。相同mid8仍按完整机器ID区分；节点名称不是唯一身份。成员册在线/下线与机器连接、原生忙闲分别显示，未进行原生发现时不推断idle。

星默认成员列表。星内按1查看成员、2查看节点、3查看全星会话；3及未指定范围的TCP会话页默认完整发现，包括未入册与匿名非归档会话，b可主动改为仅册内成员。全星会话每行显示所属节点，Enter进入该节点的会话列表；节点表Enter同样进入所选节点的完整发现。按最多三节点并发读完分页，离线/单源错误保留部分结果，Esc返回保留选择和筛选。

完整发现仍保留没有被原生结果精确命中的持久册位，包含离线或读取失败节点；这些行保留星籍、不虚构原生忙闲。空列表或已选星失联时，i仍能查看原因与具体下一步，不把无法读取误报为另一颗星。

节点、成员、TCP会话列表每两秒进行有界只读刷新，保留当前选择；详情、输入、帮助、确认和秘密结果期间暂停，离开释放旧查询。Ctrl+C可暂停，r恢复。快照读取不记录管理审计；原list-nodes/list-members审计保持。

成员页 a 打开当前星的可发现会话；选中所需节点的具体会话，再按 a 确认入星。新手动成员永久，已有临时成员保持原属性。CLI、Desktop、Web 只要能被该 node 的原生来源发现并具备入星能力，都可这样管理；TUI 不猜 GUI 当前标签。Ctrl+D 立即取消选定册位及其路由，保留原生历史和进程。

统一入口规则：经 crosschat 启动器启动的 Claude/Codex CLI 跟随首条输入和 `/resume`；直接运行原生工具、桌面/Web 统一通过 TUI 选择入星，裸 `/resume` 不自动归队。永久册位保留；node 普通断网重连重播当前声明，进程重启后仍活着的启动器重新声明当前会话，没有启动器的手动成员需在 TUI 明确恢复。其他工具的启动器适配按后续计划接入。

成员/会话页 e 按具体工具、端点和当前连接核验原生改名能力。Codex CLI 已接入，当前服务须达到 0.163.0 协议基线且能够核实同一原生 owner 和已加载会话；确认后同步原生名称与星内路由。Claude 官方 SDK 只改持久标题，未确认活窗口同步；Codex Desktop 当前协同接口没有改名入口，这两类保持禁用，使用各自原生界面改名。其他未核实来源也置灰；连接恢复后重新判断，不自动提交旧操作。没有星内别名，也不会直接修改原生历史文件。[验证与具体边界](development/native-rename-validation-20261027.md)。

所有写动作先预览并重新核对。删星列完整静态影响并要求名称确认；删除使用确认版本，在broker或冷事务同一步核验。凭证替换、label复用、机器绑定变化或删星影响新增都会拒绝；不回落其他选择器，不自动重试。撤钥立即使相应既有连接失效，保留原生聊天与永久册位。节点列表Ctrl+D按完整机器ID原子删除该星绑定到它的全部节点钥，确认列出完整集合；集合变化即拒绝。x只撤销确认的单把凭证，与删除整机分开。

星、节点、成员和会话列表都可直接k/K/x发钥或撤销，无需先进入凭证页。弹层固定原星；节点撤销还固定完整机器范围。多凭证在弹层明确选择，提交使用该凭证完整ID与确认版本，不用机器行或label代替。

新机器接入默认一份配置，需填接收机可达地址，不默默把localhost或监听通配地址当远机地址。配置已生成与机器已上线分别显示。一次性结果页按登记键复制各份配置，c复制连接指引；Esc/Ctrl+C隐藏秘密并清当前画面后返回，q清除后退出，不再次提交生成。秘密不进入普通列表、详情、偏好或错误；OS剪贴板和外部终端录像需用户自行处理。

星增删改和发吊管理钥仅broker本机；星管理员可发节点钥、撤节点钥、删除整机接入和修改在线节点的本星名称，普通成员仅本星读取与既有册位操作。节点列表e修改所选在线机器的当前星名称，可作用于远端；空值清除本星覆盖并回落该机器的全局名，不改其他星。对端持久保存并实际生效后才显示完成，离线不伪造成功。CLI全局显示名操作仍独立保留。远机日志没有TCP读取接口时给出对应SSH/原生终端指引。会话入星由选定节点重新核验完整原生身份，调用端不构造对端册位冒充成功。

星列表B/Ctrl+B只在本机Broker管理权限下启动/停止该星所属的整个broker，远端置灰。确认列完整服务身份、进程版本和全部托管星影响；服务或影响变化需重新确认。停止broker会影响它托管的所有星，不把当前选中星误当成单星停机范围，不直接调用模糊的全局停止命令。

`:tcp-targets` 的a导入当前`brokers`数组中的新星，须有完整starId，只追加，不替换同星或迁移旧形状；e编辑所选连接地址、端口及钥匙，节点钥留空保留，管理钥明确选保留、更换或移除；Ctrl+D只移除本机连接配置。普通详情和表单不会预填秘密。确认绑定原文件及目标版本，安全原子替换前再次复核，保留全局showName和无关字段；最后一项移除后保留文件并写`brokers:[]`。这不等于与无锁旧writer建立跨进程绝对CAS。

TCP配置编辑或移除不自动重启/停止服务，不删远端星，不撤远端钥匙。正在运行的节点继续使用内存配置，重启后才使用新配置；需自行核对服务与连接。broker自登记条目在后续启动时可能按现有规则补建，确认中会提示。Enter从所选配置进入该星成员列表；保存成功后重新读取真实连接清单。

管理审计沿用原动作/频率，新增完整starId作用域，按稳定身份筛选。全局显示名一次动作记录所有受影响星。旧行无完整标识时明确无法准确归属，不按相同星名混入当前星；日志仍受有界尾窗限制。

## 操作与退出（通用）

修改动作从所属资源列表发起。共享表单固定连接和目标，检查权限与影响后确认，默认选中取消；确认前再次核验，期间显示核验状态。长影响和错误说明可完整滚动，标题与取消/确认按钮始终保留。失败保留输入。表单编辑至少需要24列×16行，窗口不足时暂停编辑，放大后继续或Esc取消。

写请求发出后取消仅停止等待，显示结果待核实，不表示回滚，也不会自动重发；未确认的写入应先核实目标星册。

正常退出、Ctrl+C和异常退出会清理自有读取/监听/子进程，并恢复raw模式、光标、括号粘贴与主屏。非交互终端在读取配置和加载界面框架前退出。

## 结构与验证

`src/tui/`的展示只依赖controller快照。资源、列、动作和帮助共用登记；业务由可取消的Adapter提供，新Provider原生差异留在应用适配层。终端框架仅在 `tui` 命令动态加载。
